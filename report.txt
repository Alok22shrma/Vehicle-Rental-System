# VEHICLE RENTAL SYSTEM USING INHERITANCE

This project uses Object-Oriented Programming concepts such as classes, objects, constructors, single inheritance, function overriding, and runtime polymorphism. It also validates user input to handle invalid vehicle choices and rental durations.

## Objectives
The main objectives of this project are:

1. To develop a vehicle rental system using C++.
2. To create a base class named Vehicle.
3. To derive Car and Bike classes from the Vehicle class.
4. To calculate rental charges according to vehicle type and rental duration.
5. To display vehicle details and total rental charges.
6. To validate user input and handle invalid values.
7. To demonstrate important Object-Oriented Programming concepts.

### Vehicle Class
Vehicle is the base class. It stores common details such as vehicle ID, model name, and rental duration. It also declares functions for calculating rent and displaying vehicle information.

### Car Class
Car is derived from the Vehicle class. It inherits the common vehicle details and calculates the rental charges at a fixed rate of ₹1,500 per day.

### Bike Class
Bike is also derived from the Vehicle class. It inherits the common vehicle details and calculates the rental charges at a fixed rate of ₹500 per day.

### Class Relationship
Vehicle (Base Class)

- Car (Derived Class)
- Bike (Derived Class)
Both Car and Bike inherit common properties from the Vehicle class.

##  Algorithm
1. Start the program.
2. Display the vehicle rental menu.
3. Ask the user to select Car or Bike.
4. Validate the selected option.
5. Ask the user to enter the vehicle ID.
6. Check whether the vehicle ID is valid.
7. Ask for the model name.
8. Ask the user to enter the rental duration in days.
9. Check that the rental duration is greater than zero.
10. Create the appropriate Car or Bike object.
11. Calculate the total rental charges.
12. Display the vehicle details and total rent.
13. Release the allocated memory.
14. Stop the program.

##  Formula Used
The formula used to calculate rental charges is:

**Total Rent = Daily Rental Rate × Number of Days**

For a car:

Daily Rate = ₹1,500

Total Rent = ₹1,500 × Number of Days

For a bike:

Daily Rate = ₹500

Total Rent = ₹500 × Number of Days

### Example

If a car is rented for 3 days:

Total Rent = 1,500 × 3 = ₹4,500

If a bike is rented for 4 days:

Total Rent = 500 × 4 = ₹2,000

## Advantages
1. Calculates rental charges quickly.
2. Reduces manual calculation errors.
3. Uses inheritance to reuse common vehicle details.
4. Provides separate rental rates for cars and bikes.
5. Handles basic invalid inputs.
6. Is simple to understand and operate.

## Limitations
1. Only cars and bikes are supported.
2. Rental rates are fixed in the source code.
3. The model name accepts only one word.
4. The program does not save rental records permanently.
5. It does not manage vehicle availability, payments, or customer records.

## Conclusion
The Vehicle Rental System is a simple C++ project that demonstrates important Object-Oriented Programming concepts. It uses a base class and derived classes to represent different types of vehicles.
The project calculates rental charges according to the selected vehicle type and rental duration. It also demonstrates constructors, single inheritance, function overriding, runtime polymorphism, and basic input validation.
Through this project, we learn how OOP concepts can be applied to solve a simple real-life problem.
