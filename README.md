# Vehicle Rental System using C++

## Project Overview
This is a beginner-friendly C++ mini-project developed for the OOPS (PPF) assignment. It calculates rental charges for cars and bikes using inheritance.

## Features
- Rent a car or a bike.
- Display vehicle ID, model, rental duration and daily rate.
- Calculate total rental charges.
- Validate vehicle choice, vehicle ID and rental duration.
- Demonstrate OOP concepts.

## OOP Concepts Used
- Classes and Objects
- Single Inheritance
- Constructors
- Function Overriding
- Runtime Polymorphism
- Base-Class Pointer

## Rental Rates
- Car: Rs. 1500 per day
- Bike: Rs. 500 per day

## How to Run
1. Install a C++ compiler.
2. Compile using `g++ main.cpp -o vehicle`.
3. Run the executable using `.\vehicle.exe` on Windows.
